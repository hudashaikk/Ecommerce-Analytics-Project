# E-Commerce Sales & Customer Insights Analytics

## Project Overview

This project analyzes e-commerce sales data to identify sales trends,
customer behavior, product performance, regional performance, and
shipping patterns.

The project uses Python, SQL, Power BI, and Excel-oriented analytics
concepts to demonstrate an end-to-end data analytics workflow.

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- SQLite
- SQL
- Power BI
- Excel
- Git/GitHub

## Dataset

The dataset contains approximately 9,800 sales records with information
about orders, customers, products, categories, regions, sales, and
shipping.

## Project Workflow

1. Data loading and exploration
2. Data cleaning using Python/Pandas
3. Exploratory Data Analysis
4. SQL business analysis
5. Power BI dashboard development
6. Business insights and recommendations

## Key Analysis Areas

- Yearly sales trends
- Monthly sales patterns
- Category performance
- Sub-category performance
- Top products
- Customer analysis
- Customer segments
- Regional performance
- State and city performance
- Shipping performance
- Repeat customers
- Average order value

## Key Business Insights

- 2018 generated the highest annual sales.
- Technology generated the highest sales among the three categories.
- Office Supplies had the highest number of records but a lower average
  sales value per record.
- Sales increased strongly in 2017 and 2018 after a decline in 2016.
- Customer and product analysis identifies high-value areas for
  business focus.

## Dashboard

The Power BI dashboard provides interactive analysis using:

- Total Sales
- Average Order Value
- Total Orders
- Total Customers
- Average Shipping Days
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Sales by Segment
- Top 10 Products
